# Voice Audit — Sample Database

Fifty verbatim rows of real Cambio Labs writing, pulled from actual outbound materials and tagged
by location, speaker, audience, modality, reader action, and register. This is the evidence base
[`voice-audit-guide.md`](voice-audit-guide.md)'s eight rules were derived from — every Do/Don't in
that file cites a row number here.

**Use this before the hand-built profile cards in `../profiles/`.** Those cards were built from three
long-form documents (a pitch script, a manifesto, an album's front matter) and are still useful for
rhythm and structure — but this database is real outbound copy across every channel Cambio actually
writes for, which is the more direct reference whenever a row here matches what's being written.

value proposition to fit the reader's mindset — this is a natural strength the guide builds on, not a
gap to fix.**
